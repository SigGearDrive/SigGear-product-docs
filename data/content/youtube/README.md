## Truthful release steps

1. Record only real SigGear products, real mechanical details, approved engineering references and genuine manufacturing/inspection footage.
2. Confirm all visible diameter labels against the actual filmed model.
3. Do not imply that a pictured motor has already been validated with a particular gearbox unless the engineering team has confirmed that configuration.
4. Complete the video, subtitles, thumbnail and URL checks; then publish through the actual YouTube channel.
5. Add the **published YouTube video URL** to the production pack and five-channel weekly report. Do not mark scripts as released videos.

Existing GitHub assets and published specifications remain sources of truth; the content packs deliberately do not invent torque values or customer examples.
