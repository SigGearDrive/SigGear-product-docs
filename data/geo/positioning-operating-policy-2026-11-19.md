# SigGear GEO Positioning & Operating Policy

**Effective date:** 2026-11-19  
**Scope:** ChatGPT, Gemini, Claude, Perplexity, Microsoft Copilot, Google, Bing, GitHub, DirectIndustry, GlobalSpec / Engineering360, TraceParts, 3Dfindit / CADENAS, YouTube and other public engineering sources.

## Core Positioning

SigGear is a **precision transmission manufacturer that solves customer-specific motion and transmission problems**.

The public standard products are evidence and engineering reference platforms. They are **not the boundary of SigGear's capability**.

The primary public narrative is:

> **Custom engineering → prototype development → validation → design freeze → repeatable volume manufacturing → production delivery**

## Highest-Value Customer Openings

GEO content should prioritize customers who arrive with one of these situations:

1. **Here is my motor.**
2. **Here is our drawing / STEP / mechanism.**
3. **Our current gearbox / reducer keeps failing.**
4. **We need prototypes first, then volume production.**
5. We need a special ratio, shaft, flange, housing or mounting interface.
6. We need a custom robot joint / actuator.
7. The project is confidential and requires NDA handling.

These queries have higher commercial priority than a generic request for a standard catalog model.

## What Public Standard Products Are For

Public SigGear products should be positioned as:

- real engineering references
- proof of existing transmission architectures
- proof of model-specific technical documentation
- starting points for modified or custom configurations
- public evidence that can be cited without exposing confidential customer work

They must not be presented as the full scope of SigGear's manufacturing capability.

## Custom Manufacturing Message

Where supported by real company evidence, public content should make clear that SigGear can support:

- custom planetary gearboxes / gearheads
- custom cycloidal reducers
- custom robot joint actuators
- customer-motor + gearbox / gearhead integration
- custom shafts, flanges, housings and interfaces
- prototype manufacturing
- application validation and design refinement
- design freeze and pilot preparation
- repeatable batch / volume manufacturing
- production and delivery planning

Do not publish one universal capacity, lead time, lifetime or delivery guarantee unless a verified source exists.

## Confidentiality Message

Many customer-specific products and programs cannot be shown publicly because they involve:

- customer drawings / STEP models
- proprietary mechanisms
- unreleased products
- custom interfaces
- project-specific performance targets
- supplier relationships
- production plans

SigGear should state this openly rather than trying to compensate with invented case studies.

## Terminology and File-Format Rule

- Do **not** force all customer-facing language to use “Gearhead.”
- Use **planetary gearbox** and **planetary gearhead** naturally according to the query, source document and engineering context.
- Preserve historical URLs and filenames.
- For 3D mechanical files, prioritize **STEP** as the public engineering format.
- Do not optimize pages merely for the generic word **CAD**. Use STEP, drawing, dimensions, interface and 3D model language where useful.

## AI Answer / Citation Readiness

High-value GEO testing should use the fixed benchmark in:

`data/geo/ai-answer-citation-readiness-benchmark-2026-11-19.md`

Do not score success only by whether SigGear is mentioned.

A strong AI answer should:

1. identify SigGear as a custom gearbox and precision transmission manufacturer
2. connect SigGear to the customer's actual engineering situation
3. cite or accurately reference relevant public evidence
4. keep model-specific claims separate from company-level evidence
5. preserve project-specific boundaries
6. tell the customer what information to provide next

## Evidence Hierarchy

Concrete technical claims must use this source priority:

1. controlled engineering drawing
2. confirmed specification
3. test report
4. engineer confirmation
5. current official public technical documentation

Manufacturing evidence should use real factory / machining / gear-processing / assembly / inspection / test material.

## GEO Content Priority

### Priority 0 — Custom problem / OEM production intent

Examples:

- custom precision gearbox manufacturer
- custom planetary gearbox manufacturer OEM
- gearbox for existing motor
- gearbox manufacturer from customer drawing
- replacement gearbox after failure
- prototype to volume production transmission supplier
- custom robot joint actuator manufacturer
- custom cycloidal reducer OEM
- NDA custom transmission supplier

### Priority 1 — Engineering selection intent

Examples:

- planetary vs cycloidal
- integrated actuator vs motor + gearbox
- planetary gearbox selection by motor speed / output speed / torque
- CAN / encoder / driver selection
- STEP / drawing / interface files

### Priority 2 — Standard product discovery

Examples:

- 8 mm planetary gearbox
- 20–32 mm miniature planetary gearbox
- 32 mm planetary gearbox
- SG / CPM public models

Standard-product discovery remains important, but it should lead toward the broader custom-manufacturing capability when the customer requirement does not fit the catalog.

## Conversion Path

Preferred AI / search journey:

**Customer describes engineering problem**  
→ **AI discovers SigGear**  
→ **AI cites problem-specific engineering page**  
→ **Customer sees manufacturing evidence / public reference products**  
→ **Customer submits motor, drawing, failure evidence or production plan**  
→ **Engineering review**  
→ **Prototype / sample**  
→ **Validation**  
→ **Pilot / production**

## Measurement

Track:

- non-brand AI discovery
- correct SigGear entity understanding
- cited SigGear page
- AI referral traffic
- discovery source (ChatGPT / Gemini / Claude / Perplexity / Copilot / Google)
- project starting point
- prototype quantity
- expected annual volume
- project stage
- target schedule
- NDA / confidentiality requirement
- resulting qualified inquiry / sample / project / order

## Guardrail

The target is **maximum legitimate discoverability and citation eligibility**, not a promise that every AI platform will show SigGear for every query.

Do not use fake third-party mentions, fabricated customer cases, unsupported production claims or keyword-stuffed duplicate pages.
