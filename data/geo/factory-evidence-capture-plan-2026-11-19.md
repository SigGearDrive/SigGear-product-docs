# SigGear Factory Evidence Capture Plan for GEO

**Updated:** 2026-11-19  
**Purpose:** build verifiable public evidence for custom engineering, repeatable manufacturing and production delivery without exposing confidential customer information.

## Priority A — Volume Manufacturing Evidence

### 1. Batch component machining

Capture:
- trays / batches of real machined transmission components
- machine + parts in the same frame where possible
- multiple identical parts showing repeat manufacturing
- close-up of gears, shafts, carriers or housings after machining

Avoid:
- customer drawing numbers
- confidential model labels
- unreleased customer product geometry that identifies the project
- unsupported claims about monthly capacity

Supports AI queries:
- custom gearbox manufacturer with in-house machining
- OEM gearbox volume manufacturing
- precision transmission manufacturer for batch production

### 2. Gear processing

Capture:
- real gear-processing equipment
- gears before / after process
- batches of gears where confidentiality permits
- operator or engineer at machine

Useful context to record internally:
- process name
- part family if public
- whether image is standard product or confidential custom part
- date

Do not publish gear grade / tolerance / heat treatment unless confirmed by controlled source.

### 3. Batch assembly

Capture:
- multiple assemblies on workbench / trays
- assembly fixtures
- operators assembling real gearheads / reducers
- several identical units at the same stage

Supports:
- repeatable assembly
- volume manufacturing
- production program credibility

### 4. Quality inspection

Capture:
- dimensional inspection
- metrology equipment
- gear / shaft / housing measurement
- batch inspection scenes
- outgoing inspection where visible

Record:
- what is being checked
- whether the numeric result can be published
- model / drawing source if numeric value is shown

Do not infer accuracy or tolerance from the photograph alone.

### 5. Production testing

Capture:
- torque / speed / efficiency test setup
- noise test where instruments are visible
- temperature / thermal test
- endurance or repeated-cycle test
- motor + gearhead / joint actuator test rigs

For publishable numeric results, retain:
- exact model / configuration
- test condition
- instrument / setup
- date
- engineer approval

### 6. Packaging / shipment preparation

Capture:
- completed batch prepared for packing
- protective packaging
- labels with customer identity hidden
- multiple cartons / units where safe
- shipment preparation

Purpose:
- show production-to-delivery workflow

Do not claim delivery time from one shipment photo.

## Priority B — Custom Engineering Evidence

### 7. Drawing / CAD engineering review

Capture:
- engineer reviewing a drawing or CAD model
- screen with confidential details blurred / replaced by approved demo
- measurement against a physical sample
- discussion between sales engineer and engineering team

Supports:
- customer-drawing projects
- motor-interface review
- engineering coordination
- Luffy “factory-based sales engineer” identity

### 8. Existing motor matching

Capture:
- customer motor or approved sample next to candidate gearhead
- shaft / pilot measurement
- adapter / pinion / interface check
- assembled motor + gearhead sample

If customer-owned and confidential:
- obtain approval or use non-identifying crop
- remove customer logo / part number
- never reveal drawing or application without permission

### 9. Failed gearbox / durability review

Capture only when confidentiality permits:
- worn gear / damaged bearing / broken carrier
- measurement of failed components
- comparison between old and revised prototype
- test setup for revised unit

Public caption should describe the engineering process, not identify the customer.

Safe example:
“Reviewing gear wear and interface dimensions from an existing transmission before evaluating a revised configuration.”

Avoid:
- “We solved Client X’s failure”
- root-cause claims before engineering confirmation
- guaranteed lifetime claims

### 10. Prototype iteration

Capture:
- first prototype
- revised prototype
- interface changes
- assembly / fit check
- test setup

Best evidence sequence:
**Requirement → Prototype 1 → Test → Revision → Prototype 2 → Validation**

This is highly useful for AI understanding of custom engineering capability.

## Priority C — Prototype-to-Production Evidence

### 11. Pilot batch

Capture:
- first controlled batch after design freeze
- identical units arranged together
- inspection / assembly records with confidential data hidden
- packaging preparation

Supports:
- prototype-to-volume narrative
- repeatable manufacturing

### 12. Production schedule / material preparation

Capture:
- approved non-confidential production board
- component preparation
- batch staging
- assembly staging

Do not expose:
- customer names
- order quantities unless approved
- delivery dates for confidential programs
- pricing

### 13. Fast-delivery evidence

The public message should be evidence-based.

Good evidence:
- approved project timeline
- material ready → machining → assembly → inspection → packed sequence
- same project shown at several production stages
- confirmed delivery date only when allowed

Do not use:
- “7-day delivery” unless supported by a specific approved program
- “fastest”
- universal lead-time claims

## Minimum Metadata to Save With Every Photo / Video

Internally record:

- capture date
- location / department
- process shown
- product family or “confidential custom product”
- public / restricted / NDA status
- whether customer logo / drawing appears
- whether numeric test results are visible
- engineer who can confirm caption
- related public page

This makes future GEO content auditable.

## Publishing Rule

Every public evidence asset should answer at least one question:

1. What real manufacturing activity does this prove?
2. What custom-engineering capability does this prove?
3. What production-stage capability does this prove?
4. What can an engineer learn from it?
5. What should the customer do next?

If it proves nothing beyond “we posted today,” do not publish it.

## Highest-Value Evidence Sequence for SigGear

The strongest public story would be:

**Customer motor / drawing / failed gearbox**  
→ **engineering measurement / review**  
→ **prototype assembly**  
→ **test / inspection**  
→ **revised configuration**  
→ **pilot batch**  
→ **batch assembly / QC**  
→ **packed production units**

Customer identity can remain completely hidden.

That sequence demonstrates the capability without inventing customer cases.
