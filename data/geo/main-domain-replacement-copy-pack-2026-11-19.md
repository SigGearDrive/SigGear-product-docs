# 3. /motor-and-gear/ — Recommended Rewrite

## SEO title

Motor + Gearhead Integration & Custom Gearbox Engineering | SigGear

## Meta description

Need a gearhead for an existing motor? SigGear reviews motor speed, shaft, pilot, mounting, ratio, load, envelope and production requirements for custom motor + gearhead integration.

## H1

Motor + Gearhead Integration for Custom OEM Projects

## Lead copy

If your motor is already selected, the transmission should be reviewed around the **real motor interface and operating point** rather than selected from diameter alone.

SigGear can review:

- motor model / drawing
- loaded motor speed
- shaft diameter and usable length
- locating pilot
- mounting-hole pattern
- target output speed
- continuous and peak load
- maximum diameter and total assembly length
- prototype quantity
- expected production volume

A preliminary reduction ratio can be estimated from loaded motor speed divided by target output speed, but the final gearhead configuration also depends on stage availability, rated torque, duty cycle, interface and operating condition.

## What SigGear can evaluate

Depending on the project:

- gearhead only
- motor + planetary gearhead assembly
- custom motor interface
- custom input pinion / shaft
- special output shaft / flange
- ratio modification
- housing / mounting modification
- encoder / feedback integration where applicable
- driver / cable / connector integration where applicable
