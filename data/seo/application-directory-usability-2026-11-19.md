# Application directory usability review — 2026-11-19

**Before:** 32 application links were embedded in six long, dot-separated paragraphs. Download hubs existed, but navigation through those paragraphs was difficult to scan.

**After:** Six short industry groups display exactly the same 32 application URLs as keyboard-accessible links, with a responsive two-column grid (single column on narrow screens). Immediate top-level links to gearhead PDF/2D/STEP, motor PDFs, joint-module references and custom OEM engineering remain visible.

No new articles, no changed URL slugs, no product/engineering parameter changes, no PDF/CAD modifications. No JavaScript is required; all links remain visible to search engines and assistive technology.

**Validation:** existing application checks now additionally ensure all 32 destinations appear once in source and compiled HTML, six groups exist, and the directory stylesheet and download hubs are present.

**Search caveat:** usability changes are not a claim of improved Google ranking; evaluate CTR after recrawl.
