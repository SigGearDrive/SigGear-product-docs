# 8P-42P Planetary Gearbox Engineering Resource Library

This library organizes the current public Datasheets and controlled mechanical-interface references for SigGear's 8 mm to 42 mm standard planetary gearbox series.

Performance data is consolidated from the current canonical product pages. Mechanical-interface information is based on the controlled 2D drawings reviewed for the corresponding model.

The detailed full-assembly STEP files remain configuration-controlled because they contain internal planetary transmission geometry. Simplified public 4-stage STEP files are now released for all standard 8P-42P frame sizes.

## Data Boundary

Do not transfer torque, backlash, load, temperature or other values between frame sizes.

Where a parameter is not published for a specific model, its Datasheet states that gap rather than inferring a value from another gearbox.

## How to Use These Resources

Use the Datasheet for preliminary model / ratio / stage selection.

Use the Mechanical Interface for early packaging and mounting review.

For **32P**, use the [Public CAD Design-In Pack](../32p/design-in-pack.md) as the complete path from preliminary selection to CAD placement, sample validation and controlled configuration release.

For **42P**, use the [42P Design-In Pack](../42p/design-in-pack.md) for preliminary selection, interface review, public 4-stage STEP access, motor integration guidance and configuration-matched controlled CAD request.

For final design-in, send the selected model, ratio, stage count and motor interface so SigGear can supply the matching controlled drawing / CAD revision.
