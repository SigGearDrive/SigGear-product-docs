## Release Status

- **Product parameters:** Online technical pages publish the approved standard model data, including stages, ratios, torque, efficiency, backlash, load limits and dimensional references.
- **Gearhead and motor Datasheet PDFs:** In preparation; the online technical pages remain available.
- **2D Drawing PDFs:** Original model-specific sources have been identified for all 12 models. Public binary upload and drawing-revision verification remain pending.
- **Full Assembly STEP:** All **12 models** passed STEP structural checks on 2026-11-17. The original source files are preserved byte-for-byte in the prepared upload package. GitHub binary upload is still pending; no full-assembly download links are live yet.
- **Simplified STEP:** Available for all 12 models as separate preliminary-packaging references. Each is a **4-stage reference only**, not a full assembly.
