# Planetary Gearbox STEP CAD — 8P–42P Public 3D Models

SigGear's standard **8P-42P planetary gearbox series** now has simplified public STEP files for early mechanical packaging and Design-In.

Each released file represents the **4-stage reference configuration** for its frame size. The public CAD is intended to help engineers review installation space, external envelope, mounting interfaces and output-side packaging without exposing the internal planetary transmission construction.

## External CAD Discovery on TraceParts

The [SigGear public product catalog on TraceParts (Chinese-language portal)](https://www.traceparts.cn/zh/search/siggear?CatalogPath=GUANGDONG_1991627740%3AF_SIGGEAR) displays the **8P–42P** model range. The public 42P detail page has been opened, its 3D preview displayed, and its CAD download completed successfully. Other models' download workflows and the international English-language catalog have not yet been verified individually.

For accurate preliminary packaging, confirm that any downloaded CAD corresponds to the required frame size and **4-stage reference configuration**. Public simplified CAD is not a substitute for a controlled drawing or configuration-matched STEP model for a different reduction stage or final production release.

## Public CAD Boundary

The public STEP files are simplified external-interface references. They intentionally omit internal planetary transmission details such as internal gear geometry, carrier internals, bearings, internal fasteners and manufacturing-only features.

The released file for each model represents the **4-stage reference only**. Do not use it as a universal 1-, 2-, 3- and 4-stage model because gearbox body length changes with stage count.

For final tooling, production release or a different stage configuration, request the controlled configuration-matched drawing / CAD.

## Design-In Workflow

1. Select the frame size and ratio from the product Datasheet.
2. Download the 4-stage public STEP for early packaging.
3. Check the Mechanical Interface page for mounting and shaft references.
4. Confirm the selected stage count, ratio and motor interface.
5. Request configuration-specific controlled CAD before design freeze.
6. Validate the selected gearbox with the actual motor, load, speed and duty cycle.
