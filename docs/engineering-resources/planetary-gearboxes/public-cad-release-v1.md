## Release Status

- **Product parameters:** The current online technical pages publish the standard model data, including stages, ratios, torque, efficiency, backlash, load limits and dimensional references.
- **Gearhead and motor Datasheet PDFs:** In preparation. The online Markdown technical pages are available now; the final PDF versions will be added separately.
- **2D Drawing PDFs:** Source files have been identified. Public binary upload and drawing-revision verification remain pending.
- **Full Assembly STEP:** The 16P, 20P, 22P and 24P source files passed the STEP structural checks on 2026-11-17. Their GitHub binary upload is still pending. The other eight source files have not yet been validated in this batch.
- **Simplified STEP:** Available for all 12 models as a separate preliminary-packaging reference. Each simplified file is a **4-stage reference only** and is not a substitute for a full assembly model.
