# 24P 24 mm Planetary Gearbox - Technical Datasheet v1.0

**Status:** Public engineering evaluation reference  
**Release date:** 2026-10-06

The SigGear 24P is a 24 mm planetary gearbox platform with one- to four-stage configurations. Performance values below are consolidated from the current canonical product page. Mechanical-interface details are linked to the controlled 2D drawing reference released for this model.

## Key Specifications

| Parameter | Public value |
| --- | ---: |
| Nominal outer diameter | 24 mm |
| Number of stages | 1-4 |
| Gearbox length range | 24.6–42.0 mm |
| Reduction ratio range | 3.83:1–759.7:1 |
| Rated allowable torque range | 10.0–30.0 kgf·cm |
| Maximum momentary torque range | 20.0–60.0 kgf·cm |
| Efficiency range | 66–90% |
| Backlash at no load | ≤ 1.2° |
| Continuous permissible input speed | ≤ 8,000 rpm |
| Operating temperature range | −40 to 120 °C |

Maximum momentary torque is not a continuous working rating.

## Published Load / Shaft Limits

| Parameter | Public value |
| --- | ---: |
| Radial load, 10 mm from flange | ≤ 3.0 kgf |
| Shaft axial load | ≤ 1.0 kgf |
| Radial shaft play | ≤ 0.04 mm |
| Thrust shaft play | ≤ 0.3 mm |

Only values currently published for 24P are shown. Do not transfer limits from another frame size.

## Motor Matching Reference

- Adapted DC motor nominal voltage: **3–36 VDC**
- Adapted DC motor power: **below 28 W**

These are motor-matching conditions, not electrical ratings of the mechanical gearbox.
