# 32P Motor Integration Guide

The 32P Engineering Pack is centered on the gearbox platform, but SigGear can support three supply modes:

1. **Planetary gearbox only**
2. **Motor only**
3. **Matched motor + gearbox assembly**

## Published Adapted-Motor Range

| Parameter | Published reference |
| --- | --- |
| Motor type | DC motor |
| Nominal voltage | 3-36 VDC |
| Motor power | Below 100 W |
| Continuous gearbox input speed | <= 8,000 rpm |

The motor voltage and power values are motor-matching references, not electrical ratings of the mechanical gearbox.

## Current 32P Motor-Side Interface Reference

For the released SG01PD32 outline:

- 2 x dia. 3.1 mm motor-side mounting holes
- 22.0 +/- 0.1 mm opposed mounting-hole center spacing
- dia. 13.0 +0.05 / 0 mm central input opening
- exact motor locating-bore tolerance remains controlled by the drawing

## Information Required for Motor Matching

To evaluate a customer's existing motor or select a SigGear motor, please provide:

- motor type
- nominal voltage
- rated and peak power
- rated / no-load speed
- shaft diameter
- usable shaft length
- shaft flat / key / pinion requirement
- mounting-hole pattern
- locating pilot diameter
- available assembly length
- required output speed
- continuous and momentary output torque
- duty cycle
- ambient temperature
- expected prototype and annual quantity

## Integration Workflow

**Application requirement**  
-> select 32P stage and ratio  
-> check gearbox torque and speed  
-> check motor operating point  
-> verify shaft and mounting interface  
-> confirm assembly envelope  
-> release matched configuration drawing
