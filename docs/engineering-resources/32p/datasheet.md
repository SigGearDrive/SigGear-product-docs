# 32P 32 mm Planetary Gearbox - Technical Datasheet v1.0

**Status:** Approved for Public  
**Release date:** 2026-09-28

The SigGear 32P is a 32 mm planetary gearbox platform with one- to four-stage configurations. The public data below is intended for preliminary selection and early mechanical design-in.

## Key Specifications

| Parameter | Public value |
| --- | ---: |
| Nominal outer diameter | 32 mm |
| Number of stages | 1-4 |
| Gearbox length range | 28.05-52.95 mm |
| Reduction ratio range | 3.5:1-509.1:1 |
| Rated allowable torque range | 35.0-80.0 kgf.cm |
| Maximum momentary torque range | 70.0-160.0 kgf.cm |
| Efficiency range | 66-90% |
| Backlash at no load | <= 1.2 deg |
| Continuous permissible input speed | <= 8,000 rpm |
| Operating temperature range | -40 to 120 C |
| Housing material | Steel |
| Gear material | Steel |
| Output bearing | Ball bearings |
| Radial load, 10 mm from flange | <= 8.0 kgf |
| Shaft axial load | <= 3.5 kgf |
| Radial play of shaft | <= 0.04 mm |
| Thrust play of shaft | <= 0.3 mm |

Maximum momentary torque is not a continuous working rating.

## Supply Configuration

SigGear can supply the planetary gearbox only, the motor only, or a matched motor + gearbox assembly according to the application requirements.

The adapted-motor reference for this gearbox family is:

- DC motor nominal voltage: 3-36 VDC
- Adapted DC motor power: below 100 W

These are motor-matching conditions, not electrical ratings of the mechanical gearbox.

## Selection Information Required

Please provide:

- Required output speed or reduction ratio
- Continuous and momentary output torque
- Motor voltage, power and speed
- Motor shaft diameter and length
- Motor mounting-hole pattern and locating pilot
- Output-shaft requirements
- Radial and axial loads
- Duty cycle and ambient temperature
- Backlash, noise and service-life targets
- Prototype and annual quantity
