# SG-6010C Mechanical Interface v1.0

**Status:** Approved for Public  
**Release date:** 2026-09-28

This document is a public engineering-evaluation reference for early mechanical design-in.

!!! warning
    This page is not a manufacturing drawing. Use the released public STEP for packaging and layout checks, and request the controlled drawing before final tooling, tolerance stack-up or production release.

## Mechanical Envelope

| Item | Public evaluation value / description |
| --- | --- |
| Maximum body diameter | 80.0 mm |
| Overall product thickness | 34.07 mm |
| Rear mounting pattern | 9 x M3 through holes, evenly distributed, PCD 75 mm |
| Rear auxiliary pattern | 6 x M3, depth 5 mm, evenly distributed, PCD 74 mm |
| Rear auxiliary holes | 4 x M2 through holes, evenly distributed, PCD 40 +/- 0.1 mm |
| Output-side threaded holes | 6 x M4, effective thread depth 5.0 mm |
| Output-side dowel / reference holes | 3 x dia. 4.00 (+0.05 / 0) mm, evenly distributed |
| Connector / cable area | Represented as a simplified external envelope in the public STEP |

## Public CAD Scope

The public STEP is intentionally simplified. It retains:

- External actuator envelope
- Mounting interfaces
- Output interface
- Connector / cable envelope

It removes:

- Internal gears
- Bearings
- Motor internal construction
- PCB details
- Internal fasteners and proprietary assembly geometry

## Final Design Release

Before final tooling or production release, confirm:

- Exact ordered configuration
- Controlled mounting interface
- Cable / connector orientation
- Tolerance stack-up
- External radial and axial load condition
- Driver configuration when electronics are included
