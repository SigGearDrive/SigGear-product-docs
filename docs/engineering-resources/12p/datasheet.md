# 12P 12 mm Planetary Gearbox - Technical Datasheet v1.0

**Status:** Public engineering evaluation reference  
**Release date:** 2026-10-06

The SigGear 12P is a 12 mm planetary gearbox platform with one- to four-stage configurations. Performance values below are consolidated from the current canonical product page. Mechanical-interface details are linked to the controlled 2D drawing reference released for this model.

## Key Specifications

| Parameter | Public value |
| --- | ---: |
| Nominal outer diameter | 12 mm |
| Number of stages | 1-4 |
| Gearbox length range | 11.35–19.60 mm |
| Reduction ratio range | 3.5:1–509.1:1 |
| Rated allowable torque range | 2.0–4.2 kgf·cm |
| Maximum momentary torque range | 4.0–8.4 kgf·cm |
| Efficiency range | 66–90% |
| Backlash at no load | ≤ 1.5° |
| Continuous permissible input speed | ≤ 8,000 rpm |
| Operating temperature range | −40 to 120 °C |

Maximum momentary torque is not a continuous working rating.

## Published Load / Shaft Limits

| Parameter | Public value |
| --- | ---: |
| Radial load, 10 mm from flange | ≤ 0.8 kgf |
| Shaft axial load | ≤ 0.25 kgf |
| Thrust shaft play | ≤ 0.04 mm |

Only values currently published for 12P are shown. Do not transfer limits from another frame size.

## Motor Matching Reference

- Adapted DC motor nominal voltage: **3–36 VDC**
- Adapted DC motor power: **below 4 W**

These are motor-matching conditions, not electrical ratings of the mechanical gearbox.
