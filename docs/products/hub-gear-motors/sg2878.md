## Product Overview

SG-2878 is a 99 mm hub gear motor using a planetary reduction structure. Compared with SG-2877, it provides higher rated and peak torque for AGV, AMR, mobile robots, rehabilitation platforms and compact wheel-drive systems.

The standard catalog configuration uses Hall sensors. An external motor controller is required unless a controller is specifically included in the quotation.

## Peak Torque Condition

Peak torque: **18 Nm**

Peak-torque duration depends on the controller current limit, battery voltage, duty cycle, cooling, installation and ambient conditions. Confirm the required peak duration before selection.

## Engineering Documents

**Important source discrepancy:** the public product sheet lists an overall length of **125 mm**, but the supplied Rev A 2D assembly drawing dated 2025-07-04 shows **127 +/-0.5 mm**. Both values are retained as source data, not reconciled into a new manufacturing dimension. Confirm the installed envelope with SigGear before design-in.

The 2D drawing and Parasolid `.x_t` source are available for engineering review; neither is represented here as a tolerance-controlled manufacturing drawing or approved STEP. The 24 V test maximum is **not** a permitted continuous or peak torque rating.
