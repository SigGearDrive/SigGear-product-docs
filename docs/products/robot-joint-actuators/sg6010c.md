## Product Overview

SG-6010C is a compact 80 mm planetary robot joint actuator designed for applications that require a thin axial profile, moderate torque and relatively high output speed.

It can be supplied with or without an integrated driver. Driver, encoder, communication and closed-loop control features apply only to the driver-equipped configuration confirmed in the quotation.
