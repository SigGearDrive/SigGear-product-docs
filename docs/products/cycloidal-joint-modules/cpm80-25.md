# CPM-80-25 Integrated Cycloidal Joint Module

## Product Overview

CPM-80-25 is a compact robot joint module using an integrated cycloidal pinwheel transmission. The no-driver configuration uses an 80 mm maximum outer diameter and 29.7 mm axial thickness; the current integrated-driver reference configuration is 41.2 mm thick. The 25:1 transmission is intended for compact robot joints requiring moderate continuous torque and short-duration peak torque.

The product can be supplied with or without an integrated driver. Driver, encoder, communication and closed-loop control functions apply only to the configuration confirmed in the quotation.
