## Why This Matters When Qualifying a Custom Gearbox Manufacturer

For an OEM project, a supplier should be evaluated on more than a catalog drawing or finished assembly.

Relevant questions include:

- Can the supplier process gears, not only assemble purchased parts?
- Can the supplier measure the finished mechanical geometry?
- Can gear mesh / backlash be checked?
- Can torque, speed or life-related testing be planned where required?
- Can the same engineering program move from prototype into repeat manufacturing?

SigGear's published equipment list and customization workflow provide public evidence for these company-level capabilities. The exact process route, inspection plan and test scope remain project-specific.

## What This Means for a Custom Gearbox Project

A custom transmission program may require several different kinds of manufacturing evidence:

### Geometry

Examples:

- shaft dimensions
- pilots
- mounting features
- gear geometry
- housing dimensions

Relevant capability can include CNC machining, CMM and optical measurement.

### Gear Quality

Examples:

- tooth geometry
- mesh condition
- gear profile / lead characteristics where required
- backlash-related checks

Relevant capability can include gear manufacturing equipment, a gear testing center, gear mesh testing and backlash inspection.

### Performance

Examples:

- speed
- torque
- efficiency
- load behavior

Relevant capability can include dynamometer-based test setups.

### Durability / Environment

Examples:

- repeated-cycle operation
- life testing
- temperature exposure
- corrosion / salt spray where relevant

These tests are project-specific and should not be assumed for every product without confirmation.
