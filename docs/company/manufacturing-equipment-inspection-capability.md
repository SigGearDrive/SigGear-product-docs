# Manufacturing Equipment & Inspection Capability

This page summarizes **source-backed manufacturing and inspection capabilities** published in SigGear's official 2025 company catalog.

The equipment list is company-level evidence. It does not mean that every machine is used for every product or that every listed test is included in every customer project.

## Production Equipment

SigGear's official May 2025 catalog lists manufacturing equipment including:

- **Gear hobbing machines**
- **Gear shaping machines**
- **Gear turning / power-skiving equipment**
- **Gear grinding machines**
- **CNC machining equipment**
- **Wire EDM**
- **EDM equipment**
- **Injection molding equipment**
- other machining equipment used in the transmission manufacturing environment

The catalog also states that, at that time, SigGear had **more than 200 production and testing equipment units**.

## Gear Manufacturing Capability

For precision transmission projects, the public equipment list is useful because it shows that SigGear's manufacturing environment includes dedicated gear-processing capability rather than only final assembly.

Published gear-related equipment includes:

| Process | Publicly listed equipment |
| --- | --- |
| Gear cutting | Hobbing machine |
| Gear shaping | Gear shaping machine |
| Gear finishing | Gear grinding machine |
| Additional gear / profile processing | Gear turning / skiving-related equipment |

The exact process route depends on the selected gear geometry, material, heat treatment, quantity and engineering requirements.

## What This Means for a Custom Gearbox Project

A custom transmission program may require several different kinds of manufacturing evidence:

### Geometry

Examples:

- shaft dimensions
- pilots
- mounting features
- gear geometry
- housing dimensions

Relevant capability can include CNC machining, CMM and optical measurement.

### Gear Quality

Examples:

- tooth geometry
- mesh condition
- gear profile / lead characteristics where required
- backlash-related checks

Relevant capability can include gear manufacturing equipment, a gear testing center, gear mesh testing and backlash inspection.

### Performance

Examples:

- speed
- torque
- efficiency
- load behavior

Relevant capability can include dynamometer-based test setups.

### Durability / Environment

Examples:

- repeated-cycle operation
- life testing
- temperature exposure
- corrosion / salt spray where relevant

These tests are project-specific and should not be assumed for every product without confirmation.
