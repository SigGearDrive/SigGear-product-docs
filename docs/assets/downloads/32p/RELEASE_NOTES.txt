# 32P Public Engineering Resources

Release: v1.0
Public approval date: 2026-09-28

Public scope:
- 32P technical datasheet
- Mechanical interface reference
- Motor integration guide
- Simplified STEP - 4-stage reference

The current public STEP represents the 4-stage configuration only.

The public model intentionally omits internal planetary gear geometry, bearings, carrier internals, internal fasteners and proprietary assembly details.

Future 1-, 2- and 3-stage CAD files should be released as controlled configuration-specific assets when approved source CAD is available.

Supply options:
- gearbox only
- motor only
- matched motor + gearbox assembly
