# SG-6010C Public Engineering Resources

Model: SG-6010C
Release: v1.0
Public approval date: 2026-09-28

Public assets in this directory are intended for engineering evaluation and early design-in.

Public release scope:
- SG-6010C Datasheet v1.0
- SG-6010C Public Simplified STEP v1.0
- SG-6010C Mechanical Interface v1.0

The public STEP is deliberately simplified and does not expose internal transmission, motor, bearing, PCB or assembly construction.

Detailed CAN protocol, Quick Start, firmware-specific integration documents and related support material are request-only so the documentation can be matched to the selected driver and firmware configuration.

Driver hardware and firmware may change by ordered configuration. A future Pro driver update should be handled as a controlled revision rather than silently replacing v1.0 documentation.
