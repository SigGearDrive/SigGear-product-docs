# CPM-80-25 Public Engineering Resources

Release: v1.0
Public approval date: 2026-09-28

Public design-in scope:
- Technical datasheet
- Mechanical interface reference
- Measured 24V / 36V / 48V performance data
- Simplified STEP - no integrated driver
- Simplified STEP - current integrated-driver reference

The public STEP files intentionally omit internal cycloidal geometry, bearings, motor internals, PCB details and proprietary assembly construction.

The current driver-equipped outline is a released reference configuration. Future driver, encoder, connector or firmware variants should be published as controlled revisions rather than silently replacing v1.0.
