# Micro Pump, Valve & Dosing Gear Motors

**SigGear is an OEM supplier of DC/BLDC motors, precision planetary gearheads (Ø8–42 mm), and motor + gearhead assemblies.**

[**Motors · Datasheets**](../engineering-resources/motors/index.md){ .md-button }

**Application:** Peristaltic pumps, syringe drives and rotary valves need different speed-to-torque ratios; fluid pressure and mechanical resistance set the load.

**Engineering checks:** flow rate, shaft rpm and valve torque; occlusion / blocked-fluid peak load; sealing, cleaning and control feedback.
