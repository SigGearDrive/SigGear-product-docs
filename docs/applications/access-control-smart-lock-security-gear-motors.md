**SigGear is an OEM supplier of DC/BLDC motors, precision planetary gearheads (Ø8–42 mm), and motor + gearhead assemblies.**

**Application:** A smart lock motor drives a cam or bolt against spring force, door misalignment and battery-voltage variation.

**Engineering checks:** bolt force and cam radius; start current and low-battery operation; manual release and emergency egress.
