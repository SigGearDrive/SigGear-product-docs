# Automatic Pet Feeder, Litter Box and Pet Door Gear Motors

A feeder auger meters pellets, a litter-box drum rotates a variable load, and a pet-door latch releases a spring. Each mechanism imposes a **different torque and safety profile**, so one motor/gearhead choice cannot be assumed to cover them all.

## Separate feeding torque from a blockage

Measure normal auger torque with several food types and fill levels, then measure the **blocked-auger event** separately. For a litter-box drum, estimate torque from the eccentric load and rotation angle, and provide independent support for large drum loads rather than routing them through a tiny gearhead bearing.

## What the OEM Engineer Must Check

| Item | Required input or validation |
| --- | --- |
| **Food auger** | Portion displacement per revolution, pellet bridging, reverse-clearing logic |
| **Litter-box drum** | Starting inertia, off-centre fill mass, repeated cycles and external bearing support |
| **Pet safety** | Presence detection, motor cut-off and prevention of unintended closure |
| **Environment** | Dust, hair, washdown separation, cleanability and motor enclosure limits |

**Supply options:** Gearhead Only for a suitable existing motor, or a Motor + Gearhead Assembly after interface review. [Motor-only technical sheets](../engineering-resources/motors/index.md) are available separately.

**Boundary:** The gearhead is outside the food/litter-contact mechanism unless separately qualified. No pet-product safety approval, dust-proof enclosure rating or cleaning certification is claimed.
