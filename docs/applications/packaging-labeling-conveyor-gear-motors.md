# Packaging, Labelling & Small Conveyor Gear Motors

**SigGear is an OEM supplier of DC/BLDC motors, precision planetary gearheads (Ø8–42 mm), and motor + gearhead assemblies.**

[**Motors · Datasheets**](../engineering-resources/motors/index.md){ .md-button }

[**Motor + Gearhead Assemblies**](../custom-engineering/motor-gearbox-integration.md){ .md-button }

**Application:** Compact feeders and label rollers require repeatable speed under load changes, while conveyors need radial support beyond the gearhead itself.

**Engineering checks:** roller radius, traction and output rpm; peak start torque and continuous cycles; external bearings and shaft loading.
