# Motorized Curtains, Roller Blinds and Window Opener Gear Motors

Curtain tracks, roller blinds and window openers need different output mechanisms. A curtain rail uses a belt or pulley; a blind winds fabric onto a roller; a window opener often uses a linkage or screw. **Select the mechanism first, not the gearbox diameter.**

## Motorized curtain track: two sizing equations

For a direct-drive track pulley of radius **r**, travel resistance **F**, and curtain speed **v**, start with **T_pulley ≈ F × r** and **n_output ≈ 60v / (2πr)**, with metres and seconds. Account for pulleys, belt tension, start friction and any additional reduction. A roller blind needs its *changing winding radius* checked separately.

## What the OEM Engineer Must Check

| Item | Required input or validation |
| --- | --- |
| **Track or roller load** | Measure rail drag or lifting torque over the complete stroke, including end stops |
| **Comfort** | Test audible noise, vibration and acceptable opening/closing time in the assembled product |
| **Power-off behavior** | Specify a brake, clutch or other holding method if required; a planetary gearhead is not inherently self-locking |
| **Package & feedback** | Motor shaft, pulley coupling, wall thickness, limit switches and current sensing |

**Supply options:** Gearhead Only for a suitable existing motor, or a Motor + Gearhead Assembly after interface review. [Motor-only technical sheets](../engineering-resources/motors/index.md) are available separately.

**Boundary:** A quiet, repeatable drive requires an OEM system test. No published sound-pressure or blind-lifting performance is claimed for these generic gearhead models.
