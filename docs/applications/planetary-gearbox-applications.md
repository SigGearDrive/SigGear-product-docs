# Planetary Gearbox Applications

SigGear supplies **8-42 mm miniature and compact planetary gearboxes** for OEM products that need higher output torque, lower output speed and compact packaging.

## Why Use a Planetary Gearbox?

A planetary transmission can be useful when a project needs:

- higher torque from a compact motor
- reduced output speed
- coaxial input and output
- multiple ratio options
- compact cylindrical packaging
- motor-specific integration
- a custom output shaft or mounting interface

A gearbox should not be selected from diameter alone. Continuous torque, peak torque, speed, duty cycle, thermal condition, radial / axial load, backlash and service-life targets should be reviewed together.
