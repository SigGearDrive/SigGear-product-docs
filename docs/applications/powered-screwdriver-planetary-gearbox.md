# Planetary Gearbox for Electric Screwdrivers and Fastening Tools

Electric screwdrivers, compact nut runners and cordless fastening mechanisms commonly use a high-speed DC or BLDC motor together with a reduction gearbox to obtain lower output speed and higher usable torque.

For SigGear's current planetary gearbox program, these applications are a **potential OEM Design-In path**. This page does not claim that a specific SigGear gearbox has been validated or mass-produced in a named fastening-tool customer project.

## Where to Start by Gearbox Size

Use the gearbox diameter only as a first packaging filter. The exact model must still be checked for ratio, stage count, rated torque, length, motor interface and duty cycle.

| Starting frame group | Typical tool direction | First engineering checks |
| --- | --- | --- |
| **10P–20P — Micro / small precision tools** | precision electric screwdrivers, electronics assembly tools and compact adjustment mechanisms | low output torque, speed, diameter, noise, repeatability and motor shaft size |
| **20P–28P — Compact OEM tools** | cordless screwdrivers, moderate-torque fastening mechanisms and compact service tools | continuous torque, peak torque, loaded motor speed, duty cycle and available axial length |
| **32P–42P — High-Torque Compact** | higher-torque fastening tools, compact nut-runner mechanisms and larger motors | rated torque, peak / jam duration, shock load, motor power, bearing load and thermal behavior |

## The Main Engineering Questions

### 1. What torque is required at the fastener?

Define the **normal fastening torque** and any higher peak or stall condition separately. The gearbox should not be selected from maximum momentary torque alone.

For controlled fastening, also define whether the final torque is limited by:

- motor current
- clutch
- electronic torque control
- external torque sensor
- shut-off logic
- operator input

The gearbox provides mechanical reduction; final screw torque accuracy depends on the complete motor, driver, controller, tooling and fastening process.

### 2. What output speed is required?

Provide target output rpm or fastening cycle time. A preliminary reduction ratio can be estimated from:

**loaded motor speed / target output speed**

The actual available ratio and stage count then need to be checked against gearbox length, torque capacity and efficiency.

### 3. What motor is already selected?

If the motor is fixed, send:

- motor manufacturer and model
- motor drawing
- shaft diameter and length
- pilot diameter
- mounting-hole pattern
- loaded motor speed
- voltage
- motor power
- current limit

SigGear can evaluate a **gearbox-only** route around that motor.

### 4. What happens during a jam or hard stop?

A fastening tool may see sudden torque rise at seating, stall or a blocked mechanism. Define:

- peak torque
- peak duration
- stall strategy
- current limit
- hard-stop frequency
- reverse / release behavior

These conditions influence gearbox life and should be reproduced during sample validation.

## Application Segments

### Precision Electric Screwdrivers

Typical priorities:

- small diameter and low mass
- controlled low-speed motion
- smooth start and stop
- repeatable fastening behavior
- low vibration
- compact output interface

### Cordless Screwdrivers and Service Tools

Typical priorities:

- higher intermittent torque
- battery efficiency
- compact packaging
- repeated start-stop duty
- reasonable acoustic behavior
- scalable OEM cost

### Compact Fastening and Nut-Runner Mechanisms

Typical priorities:

- rated torque margin
- peak-load capability
- rigid output interface
- stable thermal behavior
- cycle life
- motor / gearbox alignment

## What to Send for an Engineering Review

- tool type
- normal fastening torque
- peak / stall torque
- target output rpm
- motor model and drawing
- voltage and current limit
- maximum gearbox diameter
- maximum gearbox or total drive length
