# Adjustable Furniture & Recliner Gear Motors

**SigGear is an OEM supplier of DC/BLDC motors, precision planetary gearheads (Ø8–42 mm), and motor + gearhead assemblies.**

[**Motors · Datasheets**](../engineering-resources/motors/index.md){ .md-button }

[**Motor + Gearhead Assemblies**](../custom-engineering/motor-gearbox-integration.md){ .md-button }

**Application:** Small seat tilts and screw drives depend on linkage geometry, user load and power-off holding. A gearhead is not a ready-made lifting column.

**Engineering checks:** screw lead, force and stroke; unpowered backdrive and holding; obstacle detection and repeated duty.
