# Planetary Gearbox for Electric Pruning Shears

Electric pruning shears and cordless cutting tools need high output force from a compact battery-powered drive. A planetary gearbox can reduce motor speed and increase output torque while keeping the transmission coaxial and compact.

SigGear can evaluate **28P, 32P, 36P and 42P** planetary gearbox families for pruning-shear and compact cutting-tool projects. Final selection depends on the exact motor, ratio, duty cycle, mechanism and peak cutting load.

## Start from the Cutting Mechanism

For a useful first review, provide:

- blade / linkage geometry
- required cutting force or measured output torque
- normal and worst-case material being cut
- required cycle time
- target output speed
- motor model and motor speed
- battery voltage
- available gearbox diameter and length
- expected cuts per minute / duty cycle
- target service life
- prototype and annual quantity

If torque is not known, a mechanism drawing, existing gearbox sample or measured current / cutting result can still be used as a starting point.

## Engineering Factors

### Continuous vs Peak Cutting Load

The normal operating point should be selected from **rated allowable torque**, not maximum momentary torque. Peak cutting events, jam conditions and hard branches must be evaluated separately.

### Ratio and Output Speed

The gearbox ratio should be selected from the motor speed and the required blade / linkage motion. A higher ratio can increase torque multiplication but also changes speed, gearbox length, efficiency and dynamic response.

### Duty Cycle and Heat

Pruning tools often operate intermittently, but repeated rapid cutting can still create significant motor and gearbox heating. Validation should reproduce the expected cut frequency and rest period.

### Shock and Jam Loads

A cutting mechanism can experience sudden load rise when the blade enters a hard branch or stalls. The gearbox, output shaft, linkage and motor current limit should be reviewed as a system.

### Noise and User Experience

For professional handheld tools, gear mesh noise, impact noise, vibration and backlash can affect perceived product quality. Noise targets should be defined before final gearbox release.

## Keep Your Existing Motor

SigGear can evaluate the gearbox around a customer's existing motor.

Provide:

- motor outside diameter
- shaft diameter / length
- pilot diameter
- mounting holes
- no-load / working speed
- power and current limits

Possible engineering changes can include the input interface, pinion, output shaft, mounting flange and gearbox length within the limits of the selected platform.
