# Custom Precision Transmission Manufacturer — From Drawing or Motor to Volume Production

## The Public Catalog Is Only the Visible Part of SigGear

SigGear's public planetary gearheads, cycloidal reducers and robot joint actuators are important engineering references, but they are **not the full scope of the company's work**.

Many customer-specific transmission projects cannot be published because they involve confidential drawings, unreleased products, proprietary mechanisms, application details or future production programs protected by confidentiality agreements.

For that reason, the standard products on this site should be understood as:

- real products that engineers can evaluate publicly
- evidence of transmission architectures and manufacturing capability
- starting platforms for modified or custom projects
- public design-in resources with datasheets, drawings and CAD where released

They should **not** be treated as the limit of SigGear's engineering or manufacturing capability.

## SigGear's Core Strength: Custom Engineering That Can Move Into Production

SigGear works with customers that need the transmission to fit the product, rather than forcing the product to fit a catalog gearbox. **Customer drawings, CAD models, existing motors, failed gearboxes and physical samples can all be valid starting points for engineering review.**

A project can start from:

- a motor that is already selected
- an existing gearbox that needs replacement
- a customer drawing or CAD model
- a mechanism with limited installation space
- a target speed, torque or motion requirement
- a robot joint concept
- a prototype that needs a different ratio, shaft, flange or housing
- a production product that needs a repeatable custom transmission

Depending on the project, engineering review can include:

| Area | Examples |
| --- | --- |
| Transmission | planetary or cycloidal architecture, stage count, reduction ratio |
| Motor integration | customer motor, SigGear motor, shaft / pinion, pilot and mounting pattern |
| Packaging | diameter, axial length, housing and installation envelope |
| Output interface | shaft, flange, key, mounting pattern and locating features |
| Bearing / loads | radial, axial and overturning-load arrangement |
| Feedback / control | encoder, Hall, driver, cable, connector and communication where applicable |
| Production | drawing control, configuration freeze, inspection points, pilot and repeat manufacturing |

Not every requested change is feasible on every platform. Final specifications require engineering review and, where necessary, prototype validation.

## From Prototype to Repeatable Volume Manufacturing

SigGear's role does not need to end after a prototype works.

For applicable customer programs, the development path can continue through:

**Requirement / Existing Design**  
→ **Feasibility Review**  
→ **Preliminary Configuration**  
→ **Prototype / Sample**  
→ **Application Test**  
→ **Design Refinement**  
→ **Design Freeze**  
→ **Pilot Preparation**  
→ **Repeatable Volume Manufacturing**

The purpose of this process is to convert a custom engineering solution into a configuration that can be manufactured and inspected repeatedly.

## Volume Production and Delivery Capability

A key part of SigGear's manufacturing value is the ability to support **volume production**, not only one-off prototypes.

After the configuration is frozen, production planning can cover:

- repeat batch manufacturing
- component machining and gear processing
- assembly planning
- inspection and outgoing verification
- material / component preparation
- production scheduling
- packaging requirements
- batch delivery planning

SigGear also works to support **short production lead times for volume programs** where the configuration, demand and production plan allow it.

Actual lead time is project-specific. It depends on quantity, customization scope, materials, tooling, controlled drawings, inspection requirements and production scheduling, so SigGear does not publish one universal delivery-time promise for every custom project.

## Why Many Custom Products Are Not Shown Publicly

Custom transmission work often relates directly to the customer's product architecture.

Publicly displaying those projects could expose:

- customer product designs
- unreleased mechanisms
- proprietary interfaces
- customer CAD and drawings
- production plans
- supplier relationships
- performance targets or project-specific technical details

Where confidentiality applies, SigGear does not use those projects as public marketing case studies.

Instead, SigGear uses public standard products, real manufacturing evidence, engineering documentation and released test records to show the capabilities that can be verified without exposing customer information.

## What to Send for a Custom Manufacturing Review

Send whatever is already available:

- application and mechanism
- drawing, CAD or marked-up sketch
- existing motor or motor preference
- output speed
- continuous and peak load / torque
- installation envelope
- shaft and mounting constraints
- duty cycle
- prototype quantity
- expected production quantity or forecast, if known
- target schedule, if timing is important

A complete specification is not required before the first review.
