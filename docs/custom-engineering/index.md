# Custom Precision Transmission Engineering

## Start With the Motion Problem, Not the Catalog

You do not need to know the gearbox ratio, gear structure or final motor before contacting SigGear.

You may already have a drawing and a complete specification. You may also have only:

- a motor
- a mechanism sketch
- a target speed
- a load or force requirement
- an installation envelope
- an early product concept

SigGear works with engineering teams on compact precision transmission problems using **micro planetary gearboxes, planetary reducers, cycloidal drives, motors, gear motors and integrated joint actuators**.

The first step is to understand what the mechanism needs to do. From there, the transmission structure, ratio, motor interface and other design details can be evaluated.

### Motor + Gearbox Integration

A project does not need to start with a complete SigGear assembly.

Depending on the engineering requirement, the discussion can start from:

- a customer's existing motor + SigGear gearbox
- SigGear motor + SigGear gearbox
- gearbox only
- motor only
- a matched motor + gearbox assembly
- an integrated actuator where motor, reducer, sensing and control need to be evaluated together

For an existing motor, useful starting information includes the motor drawing, shaft dimensions, motor speed, available mounting space and the required output motion.

## What Can Be Adjusted or Reviewed

The scope depends on the product family and engineering feasibility. Items that can be reviewed for applicable projects include:

| Engineering area | Examples |
| --- | --- |
| Transmission | planetary or cycloidal structure, stage count, reduction ratio |
| Motor interface | customer motor matching, motor shaft and mounting interface |
| Packaging | outer diameter, axial length, installation envelope |
| Output | output shaft, flange, mounting pattern and mechanical interface |
| Mechanical integration | housing, locating features and assembly arrangement |
| Feedback / control | encoder, driver, cable, connector and communication configuration where applicable |
| Performance target | torque, speed, backlash, external loads, duty cycle and operating condition |

Final feasibility and specifications require engineering review. Not every parameter can be changed independently, and changing one requirement may affect torque, speed, size, efficiency, life, thermal behavior or cost.

## You Do Not Need a Complete Specification

Many projects start before the transmission parameters are fully defined.

If you do not know the reduction ratio, send the motor speed and desired output speed if available.

If you do not know the required torque, send the load, mechanism geometry, arm length, wheel size, screw / pulley information or another description of how the mechanism works.

If you are not sure whether planetary or cycloidal transmission is more suitable, send the application and installation constraints first.

A simple sketch, CAD screenshot or marked-up drawing is enough to start the first discussion.

## Typical Information for an Engineering Review

Send what you already know:

- application and what needs to move
- current motor or motor preference, if any
- target output speed, if known
- torque, load or force requirement, if known
- maximum diameter, length or available installation space
- shaft and mounting constraints
- duty cycle or motion pattern
- backlash, noise or positioning requirement where relevant
- prototype quantity
- expected production quantity, if known
- drawing, CAD or mechanism sketch

Missing information can be identified during the engineering discussion.

## Engineering Development Path

A custom transmission project may move through the following steps:

**Application / Concept**  
→ **Feasibility Review**  
→ **Transmission and Motor Evaluation**  
→ **Drawing / Interface Review**  
→ **Prototype or Sample**  
→ **Testing**  
→ **Parameter or Mechanical Refinement**  
→ **Design Confirmation**  
→ **Pilot Preparation**  
→ **Production**

The exact path depends on the project. An existing platform may only require interface changes, while another project may require a different transmission or motor arrangement.

SigGear does not treat a preliminary concept as a guaranteed final solution. The design is refined through engineering review, prototype manufacturing and testing where required.
