# Failing Planetary Gearbox? Replacement and Redesign Review

If an existing planetary gearbox is discontinued, wearing prematurely, overheating, developing backlash, making abnormal noise or damaging gears / bearings, the replacement review should start from the **actual assembly, failure evidence and operating condition**, not only from the old model number.

SigGear can review its 8–42 mm planetary gearhead platforms as starting points for a replacement or modified configuration. A replacement is **not described as drop-in or fully compatible until the mechanical, performance and operating requirements have been checked.**

## What to Send First

The most useful starting information is:

1. **Existing gearbox / gearhead model** if known
2. **Old drawing, datasheet or measured dimensions**
3. **Motor model and motor drawing**
4. **Loaded motor speed and required output speed**
5. **Continuous and peak torque / load**
6. **Gear ratio** if known
7. **Output shaft or flange geometry**
8. **Motor-side shaft, pilot and mounting pattern**
9. **Maximum allowed diameter and assembly length**
10. **Duty cycle and operating environment**

If an old physical sample is available, it can be useful for checking the interfaces and construction details that may not appear on a public drawing.

## If the Existing Gearhead Has Failed

Describe the observed failure rather than only requesting a stronger replacement.

Useful evidence can include:

- worn or damaged gear stage
- tooth wear or pitting
- broken shaft or carrier
- excessive backlash after use
- bearing damage
- overheating
- abnormal noise
- lubricant condition
- load history
- approximate operating hours / cycles
- photos of the failed components

The failure evidence helps determine whether the review should focus on gear geometry, material / heat treatment, bearing arrangement, lubrication, stage selection, interface, duty cycle or another part of the system.

A replacement design should not assume that increasing one dimension or changing one material alone will solve the original failure.

## What Must Match — and What Can Change?

| Area | Review question |
| --- | --- |
| Motor interface | Must the existing motor, shaft, pilot and hole pattern remain unchanged? |
| Ratio | Must the original ratio be retained, or can output speed change? |
| Output interface | Must the existing shaft / flange / key / mounting geometry remain unchanged? |
| Envelope | Which diameter, gearbox length and total assembly dimensions are fixed? |
| Torque / load | What are the real continuous and peak loads? |
| External loads | Are radial or axial loads applied to the output? |
| Duty cycle | Continuous running, intermittent operation, holding or repeated reversals? |
| Precision | Backlash, positioning or repeatability requirement? |
| Production | Prototype quantity and expected repeat volume? |

## If the Motor Must Stay

When the customer motor cannot change, the replacement review should check:

- motor shaft diameter and usable length
- input pinion or shaft feature
- locating pilot
- motor mounting-hole pattern
- loaded operating speed
- available motor + gearhead length
- required output torque and speed
