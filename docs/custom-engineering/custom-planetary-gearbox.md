# Custom Planetary Gearbox Engineering

## When a Catalog Gearbox Does Not Fit the Project

A planetary gearbox project does not need to start from an existing SigGear model number.

You may already have:

- a motor that must be kept
- a fixed installation diameter or length
- an output-speed target
- a torque or load requirement
- a required shaft or flange
- an existing mechanism drawing
- a current gearbox that does not meet the project requirement

SigGear designs and manufactures miniature and compact planetary gearboxes and can review a project using existing gearbox platforms as engineering starting points before evaluating modified or custom configurations.

## Common Custom Planetary Gearbox Requests

Depending on the selected gearbox platform and engineering feasibility, project-specific review may include:

- reduction ratio
- gearbox diameter and axial length
- motor matching
- motor shaft and input interface
- output shaft shape and length
- mounting flange or mounting pattern
- housing and installation structure
- encoder or brake integration where applicable
- cable and connector configuration where applicable
- backlash target
- radial and axial load conditions
- duty cycle and operating condition

Changing one requirement may affect other parameters such as torque, speed, efficiency, size, service life, thermal behavior or cost. Final feasibility must therefore be confirmed as a complete configuration rather than one parameter at a time.

## I Already Have a Motor

This is a common starting point.

If the motor has already been selected, send the motor drawing or the information available for:

- motor type
- nominal voltage
- rated and peak power
- rated / no-load speed
- shaft diameter
- usable shaft length
- shaft flat, key or pinion requirement
- mounting-hole pattern
- locating pilot diameter
- available total assembly length

SigGear can then review the motor-to-gearbox interface together with the required output speed, torque and installation envelope.

The supply configuration can be:

- planetary gearbox only
- motor only
- matched motor + gearbox assembly

## I Know the Output Speed but Not the Gear Ratio

The exact ratio does not need to be defined before the first discussion.

If the motor speed and desired output speed are known, they provide a starting point for ratio selection:

**preliminary reduction ratio ≈ motor speed / desired output speed**

The final configuration still needs to account for the available stage ratios, torque requirement, gearbox input-speed limit, efficiency, duty cycle and motor operating point.

If the motor speed is not yet fixed, send the application and target output motion first.

## I Do Not Know the Required Torque

A project can still start before the torque value is fully defined.

Useful inputs can include:

- load or payload
- arm length or linkage geometry
- wheel diameter
- pulley or screw information
- friction or resistance that must be overcome
- acceleration requirement
- motion cycle
- whether the axis works against gravity
- a sketch or CAD screenshot of the mechanism

The engineering review can then identify what needs to be calculated, estimated or tested before selecting the gearbox.

## Typical Project Situations

Custom planetary gearbox engineering may be relevant when:

### The motor is already fixed

The gearbox must be adapted around an existing motor shaft, pilot, mounting pattern, speed and available assembly length.

### The gearbox must fit an existing mechanism

The project has a fixed diameter, length, mounting surface or output location that a catalog configuration does not match directly.

### The output shaft is application-specific

The project requires a different shaft geometry, shaft length, flange or mounting arrangement.

### The output speed is known but the transmission is not

The engineer knows how fast the mechanism should move but has not selected the stage count or ratio.

### The product needs a motor + gearbox assembly

The project needs the motor and gearbox evaluated together instead of sourcing the two parts separately.

### The project is moving from prototype toward production

A preliminary gearbox configuration needs to be refined around the actual motor, housing, loads, mounting and operating cycle before the design is frozen.

## Engineering Review Path

A typical custom planetary gearbox project can move through:

**Application / Existing Motor / Drawing**  
→ **Feasibility Review**  
→ **Frame Size and Ratio Evaluation**  
→ **Motor and Interface Review**  
→ **Configuration Drawing**  
→ **Prototype or Sample**  
→ **Application Test**  
→ **Parameter / Interface Refinement**  
→ **Design Confirmation**  
→ **Pilot Preparation**  
→ **Production**

The exact sequence depends on how mature the customer's design already is.

## What to Send First

You do not need to prepare a long specification sheet before contacting SigGear.

Start with the information you already have:

1. **Application** — what the mechanism needs to do
2. **Motor** — drawing or motor model if one has already been selected
3. **Output target** — speed and torque / load if known
4. **Space** — maximum diameter, length or installation envelope
5. **Interface** — shaft, mounting or drawing if these are already defined
6. **Project stage** — concept, prototype, pilot or production planning
7. **Quantity** — prototype quantity and expected production volume if known

If some of these are unknown, send the drawing, mechanism or product concept first. The missing engineering inputs can be identified during the review.
