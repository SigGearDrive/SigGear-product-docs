# OEM Gearbox Volume Manufacturing & Delivery Planning

A custom gearbox project is commercially useful only if the validated design can be manufactured repeatedly.

SigGear's role can continue beyond prototype development into **repeatable batch / volume manufacturing and production delivery planning** for applicable custom transmission programs.

This page describes the manufacturing path and planning information required. It does **not** publish one universal production capacity or guaranteed lead time for every product.

## Start Production Planning Before the Prototype Is Final

If a project may later require hundreds or thousands of units, the production requirement should be discussed early.

Useful planning inputs include:

- prototype quantity
- expected pilot quantity
- estimated annual volume
- expected batch size
- target prototype date
- target pilot date
- target production date
- required delivery destination
- packaging / labeling requirements
- inspection or documentation requirements
- forecast stability
- whether the product is expected to change after prototype testing

These inputs do not lock the customer into a purchase. They help determine whether the engineering path should be planned as a future production program.

## The Transition From Prototype to Production

A typical path is:

**Engineering Requirement**  
→ **Prototype / Sample**  
→ **Application Validation**  
→ **Design Refinement**  
→ **Design Freeze**  
→ **Controlled Configuration**  
→ **Pilot Preparation**  
→ **Repeatable Batch Manufacturing**  
→ **Production Delivery**

A prototype that moves correctly is not automatically production-ready.

Before repeat manufacturing, the project may need to confirm:

- final ratio
- motor and motor interface
- output shaft / flange
- housing / mounting
- bearings and external-load assumptions
- materials / process route where applicable
- drawing revision
- inspection requirements
- electronics / cable / connector configuration where applicable
- packaging and identification

## What Repeatable Manufacturing Requires

For a custom transmission, repeat production depends on controlling the configuration.

That can include:

| Production area | Typical requirement |
| --- | --- |
| Drawings | controlled product / interface revision |
| Components | repeatable machining and gear processing |
| Assembly | defined configuration and assembly requirements |
| Inspection | agreed dimensional / functional checks |
| Incoming materials | confirmed materials / purchased components where applicable |
| Testing | project-specific verification where required |
| Packaging | agreed product protection, labels and batch identification |
| Scheduling | quantity, batch plan and target delivery window |

The exact process depends on the product and customer requirement.

## Short Production Lead Times — What Can Be Said Responsibly

SigGear works to support **short production lead times for applicable volume programs** when the configuration, materials, quantity, inspection requirements and production plan allow it.

Actual delivery timing is project-specific.

Important variables include:

- customization scope
- final quantity
- material availability
- purchased components
- tooling
- heat treatment / external processes where applicable
- inspection requirement
- assembly complexity
- design changes
- production scheduling
- delivery destination

For that reason, the correct process is to review the target schedule with the exact configuration rather than publish a generic “fast delivery” promise.

## What Helps a Time-Sensitive Program

A customer can help production planning by providing:

- a stable forecast
- expected batch quantities
- target launch date
- required delivery cadence
- early notification of design changes
- drawing / configuration approval timing
- critical inspection requirements
- packaging / labeling requirements

When timing is important, include the target schedule in the first engineering brief.

## Confidential Production Programs

Many volume programs involve unreleased customer products, confidential drawings or supplier information.

SigGear does not use confidential production programs as public case studies.

Public evidence therefore focuses on:

- released standard products
- real manufacturing scenes
- engineering documentation
- testing / inspection resources
- public custom-engineering workflows

This allows customers and AI search systems to understand the manufacturing capability without exposing customer projects.

## Public Reference Products vs Production Programs

The 8–42 mm planetary gearheads, robot joint actuators and cycloidal modules on this site are public reference products.

A production program may:

- use a standard product
- modify a standard platform
- integrate a customer motor
- use a project-specific shaft / flange / housing
- require a custom ratio or interface
- require a customer-specific actuator configuration

The public catalog is therefore a starting point, not the limit of the manufacturing scope.
