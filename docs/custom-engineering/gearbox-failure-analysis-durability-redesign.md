# Gearbox Failure Analysis & Durability Redesign

## “Our Current Gearbox Keeps Failing. Can SigGear Review It?”

**Yes.** A gearbox failure review can start from the failed unit, old drawing, STEP model, worn-part photos, motor information or the operating condition already available.

A gearbox that keeps failing should not be replaced from the model number alone.

The first question is:

**What is actually failing, under what operating condition, and which parts of the existing design must remain unchanged?**

SigGear can review a failed planetary gearbox or compact reducer as an engineering project when the customer can provide the unit, drawing, photographs, motor information, operating condition or other failure evidence.

This is an engineering review path, not a promise that every failure can be solved by one material or geometry change.

## Typical Failure Symptoms to Document

Useful observations can include:

- gear tooth wear
- pitting or surface damage
- chipped or broken teeth
- worn sun gear, planet gear or ring gear
- carrier or pin damage
- bearing damage
- shaft damage
- increasing backlash over time
- abnormal noise or vibration
- overheating
- lubricant contamination or loss
- reduced output torque
- intermittent jamming
- failure after a repeatable number of cycles

A symptom does not by itself identify the root cause.

For example, tooth wear may relate to load, material, heat treatment, gear geometry, lubrication, alignment, duty cycle, speed, shock load, contamination or several factors together.

## What to Send

For a useful first review, provide whatever is available:

1. **failed gearbox / reducer model**
2. **physical sample**, if available
3. **old drawing or STEP model**
4. **photos of worn or broken components**
5. **motor model and drawing**
6. **loaded motor speed**
7. **required output speed / ratio**
8. **continuous and peak load**
9. **duty cycle and peak duration**
10. **approximate operating hours or cycles before failure**
11. **radial / axial load**, if applied
12. **operating environment**, if relevant
13. **what must remain unchanged** — motor, envelope, shaft, mounting or ratio
14. **prototype quantity and expected production volume**

If detailed files are confidential, the first discussion can begin with non-sensitive dimensions, operating conditions and failure symptoms.

## What the Engineering Review May Examine

Depending on the evidence and the design, possible review areas include:

| Area | Questions |
| --- | --- |
| Gear geometry | Is the stage / tooth geometry appropriate for the actual load and ratio? |
| Tooth width | Is available face width compatible with the load path and packaging? |
| Materials | Does the selected material match the intended duty and manufacturing route? |
| Heat treatment | Does the application require a different confirmed heat-treatment approach? |
| Stage arrangement | Is the load distributed appropriately across the reduction stages? |
| Bearings | Are output / internal bearings suitable for the actual radial, axial and overturning loads? |
| Shaft / carrier | Are interfaces and supporting structures contributing to stress or misalignment? |
| Lubrication | Are lubricant type, amount, retention and operating condition appropriate? |
| Speed | Does the real motor operating point differ from the original design assumption? |
| Duty cycle | Are continuous, peak, reversal and holding conditions represented correctly? |
| Assembly | Are alignment, preload, fits or assembly conditions relevant? |
| Environment | Temperature, contamination or other external conditions where applicable |

The review should be based on project evidence. SigGear does not infer a material, treatment or lifetime claim from photographs alone.

## Keep the Motor — Redesign the Transmission

Many replacement projects need to keep the existing motor, electronics and machine interfaces.

In that case the redesigned transmission may need to preserve:

- motor shaft
- locating pilot
- mounting-hole pattern
- total diameter
- total assembly length
- output shaft / flange
- output speed
- customer mounting interface

while changing one or more internal transmission details.

## What SigGear Needs Before Suggesting a Redesign

The first engineering task is to separate **failure evidence** from assumptions.

A useful initial package can be as simple as:

- the failed gearbox or reducer
- photos of the damaged gear, bearing, shaft or carrier
- the motor model / drawing and loaded operating speed
- the required output speed or ratio
- continuous load and any short-duration peak event
- approximate hours or cycles before failure
- the dimensions / interfaces that must remain unchanged
- prototype quantity and expected production volume

SigGear does not need a finished redesign specification before the first review.

## From Failure Evidence to Prototype

A practical development path can be:

**Failed Unit / Evidence**  
→ **Operating-Condition Review**  
→ **Interface Measurement / Drawing Review**  
→ **Preliminary Redesign**  
→ **Prototype**  
→ **Representative Load / Duty Testing**  
→ **Design Refinement**

The prototype should be tested against the failure mode that matters to the application rather than only checked for mechanical fit.

## From Redesign to Repeat Production

If the replacement is intended for an ongoing product, production requirements should be considered before the redesign is frozen.

That can include:

- controlled interfaces
- repeatable component manufacturing
- inspection points
- material / process definition where applicable
- pilot preparation
- batch manufacturing
- production delivery planning

## What SigGear Does Not Claim From a Failure Photo

SigGear does not automatically claim:

- the exact root cause
- a guaranteed lifetime
- zero future wear
- a perfect replacement
- 100% compatibility
- one universal material or heat-treatment solution

Those conclusions require configuration-specific engineering evidence and validation.
