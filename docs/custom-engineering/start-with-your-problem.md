## “Here Is My Motor.”

If the motor is already selected, the transmission needs to be reviewed around the real motor interface and operating point.

Useful information includes:

- motor model or drawing
- loaded operating speed
- shaft diameter and usable length
- locating pilot
- mounting-hole pattern
- target output speed
- continuous and peak load
- maximum transmission diameter and available assembly length

The final reduction ratio does not need to be known before the first review.

## “Here Is Our Drawing / STEP / Sample.”

A project can also start from a customer STEP model, mechanism drawing, installation envelope, marked-up sketch or physical sample.

SigGear can review:

- available diameter and axial length
- motor-side interface
- output shaft / flange
- locating features
- ratio and speed requirement
- bearing / external-load arrangement
- encoder, driver and communication requirements where applicable
- manufacturability of the proposed transmission arrangement

A simple mechanism drawing, STEP model or physical sample can be enough to begin identifying the missing engineering inputs.

## “Our Existing Gearbox Needs Replacement / Redesign.”

If an existing transmission must be replaced because it is failing, discontinued or no longer fits the required ratio / output / interface, the review should start from the actual unit, interfaces and operating condition.

Useful inputs include:

- old gearbox model / drawing
- actual motor
- operating speed
- continuous and peak load
- duty cycle
- photos of failed components
- approximate service hours / cycles
- output shaft and mounting interface
- available installation space
- physical sample if available

The objective is not to promise a “perfect replacement” from a photo. It is to identify **what must remain unchanged, what needs to change, and why the original unit no longer meets the project requirement** before evaluating a revised transmission.

## “We Need Prototypes First, Then Thousands in Production.”

A custom project should be evaluated as a manufacturing program, not only as a sample request.

A typical path can be:

**Requirement / Existing Design**  
→ **Feasibility Review**  
→ **Prototype / Sample**  
→ **Application Test**  
→ **Design Refinement**  
→ **Design Freeze**  
→ **Pilot Preparation**  
→ **Repeatable Volume Manufacturing**

For production-oriented projects, useful commercial / manufacturing information includes:

- prototype quantity
- expected annual volume or forecast
- target pilot timing
- target production timing
- critical inspection requirements
- packaging / labeling requirements where relevant
- expected batch / delivery plan

SigGear works to support short production lead times for applicable volume programs after the configuration, quantity and production plan are confirmed. Actual lead time remains project-specific.

## Confidential / NDA Projects

Many custom precision-transmission programs involve unreleased customer products, proprietary mechanisms and future production plans.

SigGear does not publish confidential customer designs as marketing case studies.

If an NDA is required before detailed drawings are shared, the first discussion can stay at the level of:

- application category
- target motion
- envelope
- torque / speed
- production volume
- confidentiality requirement

Detailed STEP models, drawings and project files can be exchanged after the appropriate confidentiality process is agreed.
