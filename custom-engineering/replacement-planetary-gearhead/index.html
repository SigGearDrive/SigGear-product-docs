    Existing Planetary Gearbox Replacement & Redesign¶

    If an existing planetary gearbox is discontinued, no longer fits the required ratio / output, or is wearing prematurely, overheating, developing backlash, making abnormal noise or damaging gears / bearings, the review should start from the actual assembly, interfaces and operating condition, not only from the old model number.

    “We Need to Keep the Motor and Mounting Interface, but Change the Gearbox. Can SigGear Review It?”¶

    Yes. A replacement project can start from the existing gearbox, motor, drawing, STEP model, physical sample or measured interfaces.

    SigGear is a custom gearbox and precision transmission manufacturer that can review replacement / redesign projects where existing motor or machine interfaces need to be preserved.

    The first review should separate two questions:

    1. What must remain unchanged? — motor, pilot, bolt pattern, shaft position, output interface, envelope or machine connection.
    2. What needs to change? — ratio, output speed, shaft / flange, torque capability, durability, backlash, bearing arrangement or production configuration.

    SigGear can review the old unit against the real operating condition and determine whether the best path is a standard platform, a modified platform or a custom replacement.

    Project-specific boundary: SigGear does not describe a replacement as drop-in, fully compatible or durability-improved until the interfaces, operating condition and prototype results have been checked.

    What to Send First¶

    The most useful starting information is:

    1. Existing gearbox model if known
    2. Old drawing, datasheet or measured dimensions
    3. Motor model and motor drawing
    4. Loaded motor speed and required output speed
    5. Continuous and peak torque / load
    6. Gear ratio if known
    7. Output shaft or flange geometry
    8. Motor-side shaft, pilot and mounting pattern
    9. Maximum allowed diameter and assembly length
    10. Duty cycle and operating environment

    If an old physical sample is available, it can be useful for checking the interfaces and construction details that may not appear on a public drawing.

    If the Existing Gearbox Has Failed¶

    Describe the observed failure rather than only requesting a stronger replacement.

    Useful evidence can include:

    • worn or damaged gear stage
    • tooth wear or pitting
    • broken shaft or carrier
    • excessive backlash after use
    • bearing damage
    • overheating
    • abnormal noise
    • lubricant condition
    • load history
    • approximate operating hours / cycles
    • photos of the failed components

    The failure evidence helps determine whether the review should focus on gear geometry, material / heat treatment, bearing arrangement, lubrication, stage selection, interface, duty cycle or another part of the system.

    A replacement design should not assume that increasing one dimension or changing one material alone will solve the original failure.

    Common Replacement Scenarios¶

    A replacement project does not always mean the original gearbox has failed.

    Typical reasons include:

    • original supplier or model is no longer available
    • motor must remain unchanged
    • mounting pattern / pilot / shaft location must remain unchanged
    • output shaft or flange needs to change
    • output speed or ratio needs to change
    • the existing gearbox is too long or too large
    • gear or bearing durability needs improvement
    • backlash has increased beyond the application requirement
    • a prototype replacement is needed before repeat production
    • the customer wants one controlled replacement source for future production

    The reason for replacement affects the engineering path.

    What Must Match — and What Can Change?¶

    Area Review question
    Motor interface Must the existing motor, shaft, pilot and hole pattern remain unchanged?
    Ratio Must the original ratio be retained, or can output speed change?
    Output interface Must the existing shaft / flange / key / mounting geometry remain unchanged?
    Envelope Which diameter, gearbox length and total assembly dimensions are fixed?
    Torque / load What are the real continuous and peak loads?
    External loads Are radial or axial loads applied to the output?
    Duty cycle Continuous running, intermittent operation, holding or repeated reversals?
    Precision Backlash, positioning or repeatability requirement?
    Production Prototype quantity, expected repeat volume and target schedule?

    Replacement Interface Checklist¶

    Before a replacement is described as compatible, review the critical interfaces separately:

    Interface Typical items to confirm
    Motor side motor shaft, pilot, mounting holes, pinion / input feature
    Gearbox envelope diameter, gearbox length, total assembly length
    Output side shaft / flange, key, bolt pattern, locating features
    Machine mounting bolt pattern, center position, locating geometry
    Motion ratio, output speed, direction
    Load continuous / peak torque, radial / axial load, duty cycle
    Precision backlash / repeatability requirement where applicable
    Production prototype quantity, repeat volume, inspection requirement

    A dimensional match does not by itself establish torque, thermal, lifetime or operating compatibility.

    If the Motor Must Stay¶

    When the customer motor cannot change, the motor-side interface becomes one of the primary design constraints.

    The replacement review should check:

    • motor shaft diameter and usable length
    • input pinion or shaft feature
    • locating pilot
    • motor mounting-hole pattern
    • loaded operating speed
    • available motor + gearbox length
    • required output torque and speed

    If You Only Have an Old Unit or Physical Sample¶

    A physical sample can help establish:

    • overall envelope
    • shaft / flange geometry
    • motor interface
    • mounting pattern
    • stage arrangement
    • visible wear or damage
    • dimensions missing from old documentation

    The sample should be reviewed together with the actual operating condition. A worn component may no longer represent the original manufacturing dimension.

    From Replacement Prototype to Repeat Production¶

    If the gearbox is part of an ongoing product, the replacement should be treated as a production program rather than only a one-off sample.

    A typical path is:

    Existing Unit / Interfaces
    → Replacement Engineering Review
    → Prototype
    → Application Validation
    → Design Refinement
    → Design Freeze
    → Pilot / Repeat Manufacturing

    Prototype → Volume Production Manufacturing Equipment & Inspection
