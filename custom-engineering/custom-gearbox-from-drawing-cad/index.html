    Custom Gearbox Manufacturer From Customer Drawing, STEP or Physical Sample¶

    A custom transmission project does not need to begin with a SigGear catalog model.

    “Here Is Our Drawing / STEP / Sample. Can SigGear Review and Manufacture It?”¶

    Yes. SigGear can start a custom gearbox or precision transmission review from a customer drawing, STEP model, mechanism layout, existing assembly or physical sample.

    SigGear is a custom gearbox and precision transmission manufacturer supporting OEM projects from customer geometry and engineering review through prototype validation and repeatable production.

    The first step is not to copy visible dimensions blindly. SigGear reviews the geometry together with the real motor, speed, load, duty cycle, interfaces and production requirement before a prototype or manufacturing configuration is confirmed.

    A project can continue from:

    Drawing / STEP / Sample
    → Engineering Review
    → Prototype
    → Application Validation
    → Design Refinement
    → Design Freeze
    → Pilot / Repeat Production

    Send Drawing / STEP for Engineering Review Manufacturing Equipment & Inspection Prototype → Volume Production

    Public manufacturing evidence: SigGear publishes company-level evidence for gear processing, CNC machining, CMM, gear inspection, testing and a customization workflow extending through small-batch verification, mass production and delivery. Review source-backed manufacturing facts.

    Project-specific boundary: a drawing, STEP model or sample does not by itself confirm material, heat treatment, torque rating, service life, tolerance, test scope or delivery timing.

    What You Can Send¶

    Useful starting files or evidence include:

    • 2D mechanical drawing
    • STEP model
    • assembly drawing
    • mechanism sketch
    • marked-up screenshot
    • motor drawing
    • old gearbox drawing or datasheet
    • physical sample information
    • photographs of the installed mechanism
    • photographs of failed or worn components where relevant

    A complete gearbox specification is not required before the first review.

    What SigGear Can Manufacture or Modify From a Customer Drawing¶

    Depending on engineering feasibility, the project may involve:

    • custom planetary gearbox
    • custom cycloidal reducer
    • motor + gearbox assembly
    • modified reduction ratio
    • custom input pinion / shaft
    • custom output shaft / flange
    • housing or mounting modification
    • customer-motor interface
    • bearing / external-load arrangement
    • encoder, driver, cable or connector integration where applicable
    • prototype and repeat-production configuration

    A drawing or STEP model defines geometry. It does not by itself establish the correct torque rating, material, heat treatment, bearing arrangement, service life or production process.

    What SigGear Reviews From the Drawing¶

    The engineering review may include:

    Area What to check
    Installation envelope Maximum diameter, axial length and total assembly space
    Motor interface Shaft, pilot, mounting holes, pinion / input feature and operating speed
    Output interface Shaft, flange, key, bolt pattern and locating features
    Motion target Required output speed, ratio and direction
    Load Continuous torque, peak torque, radial / axial loads and duty cycle
    Transmission structure Planetary, cycloidal or another feasible compact arrangement
    Precision Backlash, positioning or repeatability requirement where applicable
    Electronics Encoder, driver, cable, connector and communication where applicable
    Production Prototype quantity, forecast, inspection requirements and target schedule

    The drawing defines geometry. It does not automatically define the correct material, heat treatment, bearing arrangement, ratio or operating rating.

    Replacing an existing gearbox rather than developing a new mechanism? Use the Existing Gearbox Replacement & Redesign path when the motor, mounting pattern or machine interface must remain unchanged.

    If You Only Have a Physical Sample — No Complete Drawing¶

    A sample can be useful when the original drawing is missing or incomplete.

    The review may need to identify:

    • overall dimensions
    • motor-side interface
    • output interface
    • stage arrangement
    • ratio if it can be established
    • gear and shaft geometry
    • bearing arrangement
    • visible wear / failure evidence
    • installation constraints

    A worn sample must be interpreted carefully because the measured geometry may no longer represent the original design condition.

    If the Drawing Must Remain Confidential¶

    Many customer drawings relate to unreleased products or proprietary mechanisms.

    You can begin with non-sensitive information such as:

    • application category
    • required torque / speed
    • maximum envelope
    • motor type
    • prototype quantity
    • expected production volume
    • NDA requirement

    Detailed drawings can be exchanged after the appropriate confidentiality process is agreed.

    SigGear does not publish confidential customer STEP models / drawings or customer-specific products as public case studies.

    What to Send for the First Review¶

    A useful first package can be very small:

    1. drawing / STEP model / photos / physical sample
    2. motor model or drawing, if already selected
    3. loaded motor speed
    4. required output speed or ratio
    5. continuous and peak load if known
    6. maximum diameter / length
    7. interfaces that must remain unchanged
    8. prototype quantity
    9. expected annual volume or batch requirement
    10. target schedule and NDA requirement

    A complete production drawing is not required before the first engineering discussion.

    From Drawing to Prototype¶

    A typical path is:

    Drawing / STEP / Sample
    → Feasibility Review
    → Interface & Operating-Point Review
    → Preliminary Configuration
    → Prototype / Sample
    → Application Test
    → Design Refinement

    The prototype should answer specific engineering questions: fit, speed, load, thermal behavior, noise, backlash, interface or control integration as applicable.

    Manufacturing and Inspection Evidence¶

    For supplier qualification, SigGear publishes source-backed company-level evidence covering gear hobbing, gear shaping, gear grinding, CNC machining, CMM, gear testing, backlash inspection, dynamometer, life testing and other inspection / validation resources.

    From Prototype to OEM Production¶

    If the project is expected to move into production, manufacturing requirements should be considered before the first sample is treated as final.

    The later stages can include:

    Design Freeze
    → Controlled Drawing / Configuration
    → Pilot Preparation
    → Inspection Definition
    → Repeatable Batch / Volume Manufacturing
    → Production Delivery Planning

    Prototype → Volume Production

    Typical Customization Scope¶

    Depending on engineering feasibility, a project may require review of:

    • reduction ratio
    • stage count
    • motor matching
    • input pinion / shaft
    • motor pilot and mounting pattern
    • output shaft / flange
    • housing and mounting features
    • bearings and external-load arrangement
    • cable / connector
    • encoder / feedback
    • driver / communication where applicable
    • assembly and inspection requirements

    Not every parameter can be changed independently.

    Send what is already available. The first engineering discussion can identify what information is still missing.
